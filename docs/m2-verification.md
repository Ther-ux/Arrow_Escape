pytest 包含原有 34 项路径用例、14 项状态/布局用例和 5 项 UI/命中用例。窗口脚本默认打开真实 Pygame 窗口，走事件队列并逐帧绘制；它在有限帧内快速完成，并非按真实墙钟时长的观感验收。飞出和碰撞时长由 `update(dt)` 与状态测试验证，动画流畅度还需人工运行确认。

## 可复现的 UI 点击顺序

以下坐标从 0 开始，格式 `(row,col)`。逐箭点击并等待飞出，再操作下一支：

- L1：`(0,1) → (1,1) → (2,0) → (2,4) → (2,2) → (4,3)`。
- L2：`(0,0) → (0,2) → (0,4) → (2,0) → (2,2) → (2,4) → (4,0) → (4,2) → (4,4)`。
- L3：`(0,1) → (0,4) → (1,1) → (1,4) → (2,0) → (2,2) → (2,4) → (3,5) → (3,3) → (5,1) → (3,1) → (5,4)`。

以上顺序来自实际窗口自动鼠标事件脚本的输出。用于失败验收时，重开 L1，点击 `(1,1)`，每次等碰撞反馈结束后再点，共三次；应进入失败页，点击“再次挑战”应恢复六支箭头和三次机会。
